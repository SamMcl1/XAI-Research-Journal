## Decision Rationale

### Why Gaming Over Other Domains?

We reviewed six candidate domains with XAI measurability in mind:

1. **AI in Finance** — Strong regulatory/compliance angle, SHAP-ready tabular data, but stock prediction is notoriously noisy
2. **AI in Cybersecurity** — IDS models are interpretable, high stakes, but less visually intuitive for stakeholders
3. **AI in Image Recognition** — Visually compelling, but CNN explainability is approximate (DeepExplainer), computationally expensive
4. **AI in 3D Modeling** — Novel but uses concept-based explanations, not Shapley values; harder to evaluate
5. **AI in Sports Analysis** — Clean SHAP-ready tabular model, but low-stakes domain with niche audience
6. **AI in Gaming**  High personal interest overlap, active research ecosystem, real-world anti-cheat implications, model explainability is concrete

**Key decision factors:**
- All team members share genuine gaming interest (reduces friction on domain knowledge)
- Gaming AI is rapidly evolving with active recent papers (2022-2026)
- Anti-cheat systems have clear stakeholders (players, developers, compliance)
- Detection models (YOLO, Random Forest on telemetry) are SHAP-friendly and interpretable
- High stakes: false positives harm trust, explainability is essential for player confidence

### Paper-by-Paper Analysis

#### [Image Detection In The Aimbot Program Using YOLOV4-TINY](https://jutif.if.unsoed.ac.id/index.php/jurnal/article/view/821) (2023)
- **Relevance:** Concrete implementation of YOLO for aimbot detection in gameplay footage
- **Strengths:** Real model (YOLO), quantifiable performance metrics (accuracy, precision, recall)
- **Weaknesses:** Focuses on detection, not explainability; no discussion of why false positives occur
- **XAI Potential:** High—YOLO is a neural network; we could apply DeepExplainer to show which image regions triggered aimbot alerts
- **Concerns:** Real-time video analysis introduces computational complexity for SHAP computation

#### [Towards Generalized, Explainable and More Effective Server-side Anti-cheat in First-Person Shooter Games](https://www.usenix.org/conference/usenixsecurity26/presentation/zhang-jiayi) (2026)
- **Relevance:** Published at USENIX Security 2026 (top-tier venue); explicitly discusses explainability
- **Strengths:** Latest research, peer-reviewed, likely addresses multiple model types (CNNs, behavioral classifiers)
- **Weaknesses:** Focused on server-side anti-cheat (behavioral telemetry), not just aimbot detection
- **XAI Potential:** Very High—paper title promises "explainable" anti-cheat; likely uses SHAP or similar on player behavior features
- **Key Insight:** Behavioral models (movement speed, reaction time, accuracy anomalies) are tabular and SHAP-friendly

#### [Using Machine Learning for Cheating in First Person Shooters](https://arxiv.org/abs/2205.07060) (2022)
- **Relevance:** Demonstrates ML methods used by cheaters, important for understanding what anti-cheat must detect
- **Strengths:** Real-world threat modeling; helps define the problem anti-cheat solves
- **Weaknesses:** Offensive perspective (teaching cheating methods), not defensive; minimal explainability discussion
- **XAI Potential:** Low—focused on attack mechanisms, not model interpretability

#### [GAN-Aimbots: Using Machine Learning for Cheating in First Person Shooters](https://arxiv.org/abs/2205.07060) (2022)
- **Relevance:** Generative approaches to aimbot bypass (GANs generating human-like behavior)
- **Strengths:** Novel attack vector; shows evolving threat landscape
- **Weaknesses:** Duplicate entry? Same DOI as previous paper—confirm this is distinct research
- **XAI Potential:** Very High IF we focus on anti-GAN detection—GANs require deep interpretability

#### [YOLO-based object detection performance evaluation for automatic target aimbot in first-person shooter games](https://www.beei.org/index.php/EEI/article/view/6895) (2024)
- **Relevance:** YOLO performance analysis specific to gaming contexts (vs. general object detection)
- **Strengths:** Recent (2024), quantifies YOLO's strengths/weaknesses in FPS environments
- **Weaknesses:** Performance evaluation only; no explainability component
- **XAI Potential:** Moderate—could explain which game engine features (lighting, texture) confuse YOLO

### Emerging Research Focus Areas

**Option A: Detection Explainability**
- Focus: Why does the anti-cheat flag this player/behavior?
- Model: YOLO for visual detection + behavioral classifier (tabular)
- XAI Method: DeepExplainer (YOLO) + SHAP (behavioral features)
- Stakeholder: Game developers, anti-cheat engineers
- Advantage: Clear, measurable, dual-model approach

**Option B: False Positive Analysis**
- Focus: Explaining wrongful bans—what legitimate behaviors triggered detection?
- Model: Behavioral anomaly detector (tree-based, neural network on player telemetry)
- XAI Method: TreeExplainer or SHAP on temporal movement/accuracy data
- Stakeholder: Players (trust), developers (legal liability)
- Advantage: High stakes, direct business impact

**Option C: Adversarial Robustness Through Interpretability**
- Focus: Can we use SHAP to show what an aimbot must exploit? Can interpretability defend anti-cheat?
- Model: Adversarial detection model vs. GAN-aimbots
- XAI Method: SHAP + adversarial robustness metrics
- Stakeholder: Security researchers
- Advantage: Novel research angle, ties to adversarial XAI literature
